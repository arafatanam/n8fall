Privacy Policy

Last updated October 2026

n8fall is a personal, single-user script. It is run by its developer to generate and publish videos to the developer's own YouTube channel. It is not a public service, and it does not collect data from, or act on behalf of, anyone other than its developer.

What it accesses

n8fall uses Google's OAuth 2.0 flow and the YouTube Data API's youtube.upload scope, authorized directly by the channel owner. This scope is used only to:

  • Upload video files to the authorized YouTube channel
  • Set each video's title, description, tags, and privacy status
  • Schedule a video's publish time, when requested

n8fall does not read, collect, or export any other YouTube or Google account data, such as personal information, watch history, subscriptions, or analytics.

Where data is stored

The OAuth access and refresh tokens issued during authorization are stored privately by the developer, in a location only the developer controls, and are used solely to re-authorize future uploads without repeating the login step each time. No video content, script text, or token is transmitted to or stored by any third party beyond Google's own API and the stock-footage and language-model providers the script uses to generate each video.

What is never collected

n8fall does not collect data about end users, since it has none — it is operated solely by its developer on a single YouTube channel the developer owns. It does not use cookies, analytics, or tracking of any kind, since it has no website visitors to track beyond this informational page.

Changes to this policy

If how n8fall accesses or stores data changes, this page will be updated and the date above revised accordingly.
